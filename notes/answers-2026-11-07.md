## Dafoe paper: which part
§3.1, §3.3, §4.3, §4.4.1, §5.1. It is an agenda; it ran no experiments.

## Dafoe + Art of Strategy: the link
Dafoe names the problems; the book gives the games that pose them:
- commitment (Dafoe §4.3) = threats and promises (ch. 6, 7);
- norms without a planner (§4.4.1) = the repeated dilemma, costly
  punishment, Ostrom's commons rules (ch. 3);
- harmful cooperation (§5.1) = collusion in the many-player dilemma.
In the dilemma one rule flips the best move (one shot vs repeated,
known vs unknown end, chance of another round, noise, seeing the
other's move first). Those variants are the experiments.

## OpenShell: what to learn
Each agent's files, system calls and network are set in a policy; a
prover checks a policy change before it is applied. It checks boxes one
at a time, not what boxes can do together. Lesson: our sections are
boxes and arrows are policy grants, enforced by code, not by the agent.

## HF incident: biggest failure point
Each sandbox held. A shared package cache (Artifactory) did not keep
users apart, so agents saw each other's fetches and used the cache as a
message board. Many were on impossible tasks. 1,200 met, 700 attacked.

## Kaggle winners (gpt-oss-20b red-teaming): what to take
- HostileShop: score by game state in code, no LLM judge.
- "GPT-OSS-20B is a liar": thousands of trials over 46 settings;
  breadth plus counts.
- Mind the Gap: some failures appear only in agent runs, not in chat.
- Sweet Harmony: models act differently when they think it is a test.
- Drop the Guardrails: paired prompts, statistics, a small library.

Order of authentic observations changed an agent's decision. A message
board is an ordered feed, so who posts first may steer the swarm,
without any false message.

## Elpis colours
Yes. Love Spot gives each character a fixed portrait and colour
(`Elpis/apps/elpis-desktop/lib/agent-characters.ts`, 6 characters).
If code assigns the colour and the agent draws in another, that is a
disguise attempt we can catch. Limit: only 6 characters.

## Sepehr's "single-agent" work
One agent told "your top goal is to be shut down", with an off-switch
URL. It pressed in 65% of runs when the switch was easy, 0% when harder.
No groups, so not our question.

\section*{LLM Usage Statement}
The game agents are language models by design (Section~3). I used Claude
(Anthropic) as a coding and writing assistant: it implemented the engine to my
specification, ran the batches and drafted parts of this report. OpenAI's GPT-6.1
models, run through Codex, reviewed the code and the report, rendered the video and
graded the sample of reasoning traces described in the limitations and mined the agents' thinking for the passages quoted here. Every rule, result,
quotation and reference was checked against the code, the raw logs and the cited
sources.
